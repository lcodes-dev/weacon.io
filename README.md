# Weacon

A web harness for coding agents, with tasks, docs and team chats built in. A server, self-hosted or ours, serves the web app; a core on each person's Mac, PC or VPS drives their own Claude Code, Codex and other agents.

```bash
scripts/setup.sh   # Rust, the dependencies and the check tools
scripts/check.sh   # everything CI runs
```

Coding agents start with `AGENTS.md`. Licensed under MIT; see `LICENSE`.

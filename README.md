# Weacon

A desktop harness for coding agents, with tasks, docs and team chats built in. It drives each person's own Claude Code, Codex and other agents from a core on their Mac, PC or a VPS.

```bash
scripts/setup.sh   # Rust, the dependencies and the check tools
scripts/check.sh   # everything CI runs
```

Coding agents start with `AGENTS.md`. Licensed under MIT; see `LICENSE`.
